# Futsalturnier Ilanz – Website

Einfache Website für die Anmeldung zum Futsalturnier des Sport Klub 42.

## Dateien

| Datei | Wofür |
|---|---|
| `index.html` | Alle Texte. Hier änderst du fast alles. |
| `style.css` | Aussehen (Farben ganz oben). Musst du normalerweise nicht anfassen. |
| `logo.svg` | Logo Sport Klub 42 |
| `favicon.svg` | Kleines Logo im Browser-Tab |
| `twint-qr.png` | **Platzhalter** – durch euren TWINT QR-Code ersetzen (gleicher Dateiname) |

## Was du ändern musst

In `index.html` nach **✏️ ÄNDERN** suchen. Alles in `[eckigen Klammern]` ersetzen:

1. Halle, Adresse, Zeiten, Anmeldeschluss
2. Google-Formular-Link (kommt **2×** vor: `[DEINE-FORMULAR-ID]`)
   - In Google Forms: **Senden** → Symbol **`<>`** → im Code den Link bei `src="…"` kopieren
3. IBAN, Bank, Empfänger
4. Kontakt-E-Mail und Instagram
5. `twint-qr.png` durch euren QR-Code ersetzen

## Online stellen mit GitHub Pages (gratis)

1. Auf github.com einloggen → **New repository** → Name z. B. `futsal-ilanz` → **Public** → Create.
2. **Add file → Upload files** → alle Dateien aus diesem Ordner hineinziehen → **Commit changes**.
3. **Settings → Pages** → bei *Branch* `main` und `/ (root)` wählen → **Save**.
4. Nach 1–2 Minuten ist die Seite online unter
   `https://DEIN-NAME.github.io/futsal-ilanz/`

Später etwas ändern: Datei auf GitHub anklicken → Stift-Symbol → ändern → **Commit changes**. Nach einer Minute ist es online.

## Wichtig

- Das Repository ist öffentlich. Keine Anmeldungen oder persönlichen Daten hier speichern – die landen im Google-Formular bzw. Google Sheet.
- Zahlungen mit den Anmeldungen abgleichen: Im Google Sheet eine Spalte „Bezahlt“ hinzufügen und abhaken.
